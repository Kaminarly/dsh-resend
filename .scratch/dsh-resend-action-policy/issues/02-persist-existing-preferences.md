## 验收条件

- [x] 保留内联编辑方式的现有含义，将原重新生成显示设置改名为「显示重新生成按钮」，保留原配置标识；两个设置默认开启。
- [x] 从设置页到宿主保存、客户端订阅和实际显示行为形成完整路径；已保存宿主配置是权威值，不能仅使用页面内存或假定浏览器存储按 Profile 隔离。
- [x] 同一 Profile 的会话共用设置，不同 Profile 不串值；保存后刷新页面、重启测试宿主，两个值均可恢复。
- [x] 初次读取和保存显示 spec 约定状态；读取失败不视作首次使用。保存失败显示准确提示并恢复权威值；写入结果不确定时重新读取，允许重试。
- [x] 防止重复保存；保存成功前保持之前的正式生效值。缺失字段默认开启，保留合法旧值；无效值不影响其他合法字段。
- [x] 设置未读到或权威值无法确认时，相关编辑、重新生成和放入 Composer 入口暂不可用；不额外阻止普通复制、Composer 新消息及已核验的合法补发。
- [x] 提供后续范围设置复用的保存与订阅路径；同 Profile 其他页面和断线重连后能够重新读取配置。跨范围操作的完整组合由 05 验收。
- [x] 保存或刷新配置不通过重挂载聊天界面清空正在编辑的文字；新增宿主配置依赖经过兼容核对。
- [x] 完成两个设置的真实保存与读取、Profile 隔离及故障模拟验证，更新适用的原有断言、语言文案、用户说明与生成产物。

## 任务边界

只交付现有两个设置的持久保存，不提前显示尚不能真正控制操作的新范围开关。01 可以独立实施；01 尚未完成时，旧隐藏开关仍是过渡行为，本任务不为它新增保存能力。

各任务均需保留原有中文原文、补齐适用语言文案、更新受影响的测试与生成产物，并实际验证本项完整行为。不得将尚未通过验收的行为描述成已完成。

## Answer

两个现有设置已接入宿主按 Profile 保存的配置路径，保留配置标识与内联编辑含义，两个默认值均为开启。「显示重新生成按钮」只控制按钮显示。本项完成读取、保存、失败恢复、重试及同 Profile 多页面同步；设置未读取或无法确认时暂停相关入口，普通复制、新消息及已核验的补发不增加限制。保存或重新读取不会清空已打开的编辑文字，后续范围设置可以复用当前保存与订阅路径。

本项未提前增加操作范围开关；跨范围操作组合仍由任务 05 验收。原有中文内容保留，英文名称和状态、适用断言、使用说明及生成产物已更新。
