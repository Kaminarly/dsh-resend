- [x] 该设置常驻显示 spec 原文：「关闭后可重新生成较早回复。操作将从该回复对应的问题重新续接，其后的对话将退出当前上下文，原始记录仍保留。」开启和关闭时说明均可见。
- [x] 范围开启时较早回复保留置灰图标，鼠标和键盘不能执行；图标下方准确提示「只能重新生成最后一条回复」，键盘可读取提示。

- [x] 按当前有效对话判断最后一条助手回复，不将历史窗口末尾、最大 seq、工具记录、Turn 或显示片段当作判定依据；后续用户消息本身不改变最后一条助手回复。

- [x] 关闭范围限制不取消正在生成、已被替换、无文字等原有保护；合法的既有补发不被误当成新的重新生成而拒绝。
- [x] 操作较早回复时沿用 Replay turn，发送正确原问题，后续对话退出模型上下文、原始日志保留，不弹确认框、不创建 Branch。

## Answer

「只允许重新生成最后一条助手回复」已贯通设置、按 Profile 保存、按钮和实际执行，默认开启，与显示及编辑设置独立。较早回复在限制开启时置灰并提供下方提示，关闭后从正确原问题重新续接，后续内容退出有效上下文、原始日志保留。最后一条依据完整有效对话中的助手记录判断，历史窗口及后续用户消息不改变这一判定。

实际请求在会话锁内及第一条回退事件写入前核验已保存规则与目标，排队或读取期间的规则、目标变化不会导致部分回退或提前发送。非助手目标明确拒绝；既有合法补发仍只发送欠下的问题，其他已被替换回复不能冒充补发。正在生成、已被替换和无文字等保护保留。

本项未新增编辑范围设置，未更改固定隐藏任务的状态。原有中文、对应英文、适用检查、测试、生成产物和使用说明已同步。
