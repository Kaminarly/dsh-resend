**Type:** task

## Answer

已完成跨窗口规则与合法补发的交叉验证。同一 Profile 的四个设置同步到独立页面；旧按钮尚未同步时，实际请求仍按最新保存规则拒绝无效操作，不产生回退或 prompt 副作用。不同 Profile 使用各自保存值。

断线重连会重新读取完整有效对话资格，并丢弃此前在途旧响应。聊天窗口尚未重新载入时，旧消息邻接关系不能放行无效目标；已打开编辑草稿保留。保存失败和写入成功但响应丢失时，重新读取真实保存状态；延迟写入响应不会覆盖另一页面的新保存值。

两类操作已完成回退但 agent 尚未接收的准确 prompt，仍可在两个限制开启或设置读取失败后补发，不再次写入 Audit claim／Carrier。正在生成、日志不可读取、换目标或换编辑文字的请求仍受核验。存活 Session 中已观察到的 agent 接收事实覆盖消息尚未追加到日志的间隙，阻止重复交付。页面刷新及 Host 重启后的恢复范围不增加；04 已记录的旧无摘要 Carrier 兼容限制继续适用。
