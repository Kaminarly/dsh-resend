# 回滚数据清理布局与处理反馈

Status: resolved

## 请求与完成标准

为长时间处理加入转圈动画，并使用 prototype 和 ui-ux-pro-max 优化设置页中的清理功能。读取、预览、执行和取消均应有明确反馈；保留原有中文说明、清理范围和确认流程；完成界面检查、构建和测试。

## 布局决策

比较了双入口卡片、侧栏分区、分步流程三种临时原型，选择双入口卡片。两种清理方式各自说明用途，下方集中显示会话选择、预览确认或结果。侧栏分区会压缩会话路径的展示空间，分步流程在已有设置页中占用较多高度。

原型已归档到独立分支 `codex/prototype-storage-cleanup-20261011`，提交 `9dee683`，路径 `.prototype/storage-cleanup/`。在该分支运行 `node .prototype/storage-cleanup/serve.mjs`，访问 `http://127.0.0.1:43131/?variant=A`；A、B、C 可通过底部切换栏切换。原型只使用内存中的模拟数据。

## 实现结果

- 两个清理入口采用卡片布局，当前入口高亮；会话列表增加标题、数量、选中高亮和「无文件快照」标记。
- 底部显示已选数量，预览和确认操作集中展示。空间、删除影响、失败及跳过原因保留。
- 读取、预览、执行和取消期间显示转圈图标和对应说明；预览、确认、取消按钮也显示动画，处理期间禁用重复提交。
- 支持浅色和深色主题、键盘选择、功能区宽度变化，以及系统减少动画偏好。
