# 仅文件回滚与 A 方案面板

用户于 2026-10-11 要求移除独立的对话回滚，仅保留文件回滚，并先审阅原型；审阅后选择 A 方案。

界面采用轻量折叠布局：默认仅显示标题、说明及预览按钮；预览后显示数量、文件名称、目录、处理状态和无法还原原因；确认按钮显示可还原数量，没有可还原文件时隐藏；取消及收起结果恢复紧凑入口。适配宿主主题和窄窗口。

执行范围限定为文件。移除独立的对话回滚及同时回滚两者的后台实现和接口声明。保留省略范围或指定 artifacts 的文件调用；拒绝 conversation 和 both。编辑重发、重新生成依赖的 Replay turn 机制保留。

文件保护继续采用原先的内容核验：确认前不写文件，预览失效时拒绝执行，执行中变化时停止并报告已还原与未还原清单。文件操作不修改会话记录，也不补发提示词。

实现与验证见 [需求 01](issues/01-file-only-panel.md)。

2026-10-11 补充：收起结果必须保留完成标记；成功结束后结果持久保存，刷新或重启恢复，并阻止同一重写点重复还原。只有新重写点或未成功完成的操作可以重新预览。修复与验证见 [需求 02](issues/02-persist-completed-result.md)。

2026-10-11：用户要求替换安装，已安装并启用，安装文件一致性及已安装副本的隔离启动验证通过。见 [安装记录](issues/03-install-updated-plugin.md)。

2026-10-12：用户确认原版面板的重发前置原型，授权实现，并要求无文件改动时直接发送。新操作先处理文件，再撤回旧对话与发送消息；历史面板保留仅文件回滚职责。见 [需求 04](issues/04-replay-preflight.md)。
