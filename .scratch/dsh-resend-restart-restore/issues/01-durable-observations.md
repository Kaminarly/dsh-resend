# 重启后保留文件还原能力

Status: resolved

## 问题与完成标准

文件写入后，编辑重发和重新生成可以预览并还原文件；重启 DSH Desktop 后，同一文件变为「缺少可靠的原始内容」。完成标准是重新加载会话和 Host plugin 后仍能预览并实际还原，且保护外部修改、兼容数据清理。

## 原因

`createFileVersions` 原先只把工具写入前后的字节保存在内存 `observations` 中，到生成重写点或前置预览时才建立持久记录。重启或会话释放会清除内存，所以尚未形成记录的工具写入失去前置内容。原有重启测试先建立了重写点，未覆盖「工具写入后、首次重发前重启」这条路径。

## 修复

- 工具执行结束时保存私有内容引用及会话、工具调用身份记录；原始内容保持为私有快照。
- 新 Host plugin 从持久记录重新读取写入前后字节，校验调用身份、工作目录、工具参数及内容地址。
- 连续写入仍按原有规则合并；文件后来发生变化时拒绝还原。
- 会话数据清理包含写入观察记录，保留其他记录依赖的共享内容；无用残留清理保留可识别会话的观察记录。

## 限制

旧版本重启后已经丢失、没有持久副本的原始内容不能自动重建。存储失败会记录错误，保留本次内存观察；未成功保存的观察无法保证跨重启恢复。重启不会自动确认文件还原或继续发送消息。
