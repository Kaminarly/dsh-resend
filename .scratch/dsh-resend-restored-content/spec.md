# 完成后查看还原内容

日期：2026-10-14。Status: ready-for-human

用户要求在文件回滚已结束的文件行右侧增加按钮，点击弹窗查看本次还原后的结果，并在交付时提交代码及安装插件。

- 已确认还原成功的文件显示「查看还原内容」；保留、无法还原和结果不确定的文件不提供入口。
- 展示本次还原所用的保存内容及行号、BOM、换行格式，不读取后续修改的工作文件充当结果。
- 读取绑定会话、回滚点及已保存完成结果的成员，校验内容完整性，不开放任意路径和快照地址。
- 删除、空文件、非文本、超限、记录清理或损坏都有明确说明。正文上限为 3 MiB、10,000 行、单行 20,000 个 Unicode 码点。
- 刷新、重启和助手继续生成后仍可查看；关闭、切换会话和清理后的迟到响应不得重新显示。
- 复用宿主弹窗、按钮与主题，验证浅色桌面和深色窄窗口，支持 Escape 关闭及焦点返回。
- 查看不写工作文件、不写 Session log、不触发生成、不重复还原，不新增长期正文副本。

验收：真实文件和严格请求校验、界面测试、浏览器操作与截图、完整测试、构建检查、安装包字节核对，以及安装后的文件和启用状态检查。
