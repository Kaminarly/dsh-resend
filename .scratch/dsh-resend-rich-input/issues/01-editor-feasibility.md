Type: prototype
Status: resolved

**What to build:** 在不操作真实用户会话的隔离环境，完整验证「带引用的旧消息 → 独立编辑器 → 修改引用 → 接收最终文本」，确定能够在插件中打包运行的编辑器方案。

**Blocked by:** 无，可立即开始。

- [x] 原型使用代表性历史文本，包含中文、带空格文件、同名不同路径、目录和多个 skill；保留路径与正文顺序。
- [x] 文件为可删除标签，skill 为可编辑文字；可复制粘贴、撤销、编辑引用前后文字；未知内容保留原文。
- [x] 下钻中的开放引号与最终选定的目录引用区别明确；最终引用不吞入后续正文。
- [x] 导出文本交给接收替身，与宿主等价引用语法一致；没有真实模型请求或真实会话变更。
- [x] 验证依赖可打包并能在宿主浏览器模块环境运行；没有使用正式 Composer 的私有 editor 或 Trigger controller。
- [x] 记录编辑器选择、已运行验证及限制；若首选方案失败，完成替代方案验证后再结束任务。
