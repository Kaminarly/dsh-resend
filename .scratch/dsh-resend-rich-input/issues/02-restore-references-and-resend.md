# 02 — 在临时输入框保留原引用并完成编辑重发

Type: task
Status: ready-for-agent

**What to build:** 打开已发送消息时，临时输入框显示并保留原文件标签和 skill 文字，用户编辑后仍通过已有 Edit-and-resend 流程续接对话。

**Blocked by:** [01 — 验证独立编辑器的引用编辑与文本发送](01-editor-feasibility.md)。

- [ ] 原引用完整恢复，允许删除或替换；同名标签保留不同完整路径，无法可靠识别的文本不被猜测改写。
- [ ] 发送前一次性导出最终文本，沿用原有文本契约和用户来源；新增字段或普通追加发送不能代替编辑重发。
- [ ] 当前页面内退出、取消和重开同一有效目标保留草稿；成功后清理草稿，拒绝或失败后保留内容；刷新持久化不纳入承诺。
- [ ] 预检期间禁止正文与标签编辑，取消预检恢复本次编辑；现有固定文本补发行为保持正确。
- [ ] 保留操作范围、运行中禁用、目标失效保护、空白不可发送与原有中文文案。
- [ ] 没有菜单时 Enter 重发、Shift+Enter 换行、Escape 退出；输入法确认不发送。首次打开末尾聚焦，中间编辑不跳光标。
- [ ] 普通 Composer 的文字、附件、选区和撤销历史不受影响；草稿按 Session 与消息 seq 隔离。
- [ ] 在真实浏览器控件中验证编辑、重发、取消和失败，并检查接收替身得到的完整文本；已有相关回归通过。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。
