# 03 — 用 @ 引用文件、文件夹与外部路径

Type: task
Status: resolved

**What to build:** 临时输入框输入 @ 后搜索目标会话的文件或目录，支持目录下钻和宿主可搜索的工作区外路径；选中后形成可编辑标签并通过现有流程重发。

**Blocked by:** [02 — 在临时输入框保留原引用并完成编辑重发](02-restore-references-and-resend.md)。

- [x] 使用宿主公开文件查询能力，绑定目标 Session；完整路径区分同名文件，不扫描其他会话或返回会话引用。
- [x] 支持中文、带空格文件及目录、相对路径和外部绝对路径；选择只替换当前触发词或选区，邮箱中的 @ 不误触发。
- [x] 目录下钻与选定目录是不同动作，可返回上级或修改查询；最终目录标签及发送文本不吞入后续正文。
- [x] 文件、目录和外部路径标签均可恢复、删除、替换、复制粘贴和撤销，不因同名指向另一条路径。
- [x] 独立菜单支持鼠标、方向键、Enter/Tab 选择；菜单关闭后才允许 Enter 重发，Escape 先关菜单；中文输入法确认不发送。
- [x] 请求可取消；草稿、选区、查询或编辑器变化后旧响应不显示、不插入；关闭编辑器取消请求。
- [x] 加载中、空列表、接口缺失和查询失败状态可区分；失败保留原文并允许纯文本重发，不自动删除原引用，不擅自扫描目录。
- [x] 从文件和目录选择到重发接收文本的完整行为可验证；覆盖候选逆序、光标移动、目录下钻、带空格外部路径及标签撤销。
- [x] 引用仅传路径，界面不声称已经读取内容或上传文件，普通 Composer 草稿不受影响。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。

## Answer

2026-10-12：已完成独立文件引用菜单。临时输入框的 `@` 查询绑定目标 Session，使用宿主公开文件查询接口，仅接收文件和目录候选，以完整路径区分同名目标。外部绝对路径按宿主返回结果处理；宿主未返回的路径不通过自行扫描补充。引用仍导出为路径文本，沿用已有编辑重发流程，不改动普通 Composer 草稿。

「进入目录」和「引用目录」是不同操作，可返回上级或编辑查询。带空格路径使用闭合引号生成最终标签，保留后续正文；光标位于触发词中间时替换完整触发词，选区操作只替换当前选区。裸查询以空白为边界，换行后可重新触发，邮箱中的 `@` 不打开菜单。

菜单支持鼠标、方向键和 Enter/Tab 选择，长列表自动滚动到当前候选。菜单关闭后 Enter 才重发，Escape 先关闭菜单再退出编辑，输入法确认不选择或发送。加载中、空列表、接口缺失和查询失败分别提示；失败保留原文和已有标签，允许关闭菜单后按原文重发。

正文、选区、查询或编辑目标变化时取消旧请求，旧候选和旧目录按钮不能插入或修改新草稿。关闭编辑器、连接重置、目标会话预设或工作目录变化时，引用恢复请求和候选查询均失效，已有正文及标签保留。文件、目录和外部路径标签继续支持恢复、删除、替换、复制粘贴、撤销和重做。
