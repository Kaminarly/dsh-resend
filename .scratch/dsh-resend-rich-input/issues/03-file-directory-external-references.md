# 03 — 用 @ 引用文件、文件夹与外部路径

Type: task
Status: ready-for-agent

**What to build:** 临时输入框输入 @ 后搜索目标会话的文件或目录，支持目录下钻和宿主可搜索的工作区外路径；选中后形成可编辑标签并通过现有流程重发。

**Blocked by:** [02 — 在临时输入框保留原引用并完成编辑重发](02-restore-references-and-resend.md)。

- [ ] 使用宿主公开文件查询能力，绑定目标 Session；完整路径区分同名文件，不扫描其他会话或返回会话引用。
- [ ] 支持中文、带空格文件及目录、相对路径和外部绝对路径；选择只替换当前触发词或选区，邮箱中的 @ 不误触发。
- [ ] 目录下钻与选定目录是不同动作，可返回上级或修改查询；最终目录标签及发送文本不吞入后续正文。
- [ ] 文件、目录和外部路径标签均可恢复、删除、替换、复制粘贴和撤销，不因同名指向另一条路径。
- [ ] 独立菜单支持鼠标、方向键、Enter/Tab 选择；菜单关闭后才允许 Enter 重发，Escape 先关菜单；中文输入法确认不发送。
- [ ] 请求可取消；草稿、选区、查询或编辑器变化后旧响应不显示、不插入；关闭编辑器取消请求。
- [ ] 加载中、空列表、接口缺失和查询失败状态可区分；失败保留原文并允许纯文本重发，不自动删除原引用，不擅自扫描目录。
- [ ] 从文件和目录选择到重发接收文本的完整行为可验证；覆盖候选逆序、光标移动、目录下钻、带空格外部路径及标签撤销。
- [ ] 引用仅传路径，界面不声称已经读取内容或上传文件，普通 Composer 草稿不受影响。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。
