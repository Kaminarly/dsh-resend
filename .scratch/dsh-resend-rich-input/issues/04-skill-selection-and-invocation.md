# 04 — 用 / 选择并调用 skill

Type: task
Status: resolved

**What to build:** 临时输入框输入 / 后可选择当前目标会话允许用户调用的 skill；选择结果保留为可编辑文字，并在重发后交由宿主加载。

**Blocked by:** [03 — 用 @ 引用文件、文件夹与外部路径](03-file-directory-external-references.md)。

- [x] 复用独立候选菜单，使用宿主按目标会话筛选的 skill 列表，不自行扫描技能目录；菜单不加入其他 slash 命令。
- [x] 选中后插入可编辑技能名称及正确空白边界，支持句中选择、多个 skill、删除和替换；文件路径、分数不误调用。
- [x] 菜单键盘和输入法规则与文件选择一致；查询结果可取消，旧结果不插入新草稿。
- [x] 历史技能已失效、改名或不可供用户调用时提示，但保留并允许原文发送；查询失败不能提示为确定不存在。
- [x] 同名宿主命令不执行；只有符合调用规则且可供用户调用的 skill 会加载，其他内容提示后作为普通原文发送。
- [x] 宿主真实技能加载钩子收到重发的用户文本后加载代表性 skill 指令，重复名称按宿主规则去重；不存在或仅模型可调用的 skill 不被伪装成调用成功。
- [x] 验证菜单到重发、技能加载、失效提示后发送的完整行为，接收与技能注册表可用隔离替身，不操作真实用户会话。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。

## Answer

2026-10-12：已完成临时输入框的技能选择与调用。文件和技能复用独立候选菜单；技能列表来自宿主按目标 Session 筛选的公开查询接口，不扫描技能目录，也不加入其他 slash 命令。技能选中后保留为可编辑的 `/名称` 文字，必要时补足空白边界；支持句中选择、多个技能、光标与选区替换、删除、撤销和重做。

菜单沿用文件选择的键盘规则：方向键切换候选，Enter/Tab 选择，关闭菜单后 Enter 重发，Shift+Enter 换行，Escape 先关闭菜单再退出编辑。中文输入法确认不选择或发送。查询绑定目标会话；草稿、选区、查询或编辑器变化后取消旧请求。连接重置、目标预设事件和会话查询范围变化使旧候选失效；其他会话的预设事件不影响当前菜单。

历史与编辑中的技能文字会重新确认可用性。已失效、改名或不可供用户调用时提示并保留原文；接口缺失、查询失败或不可读的查询结果只提示无法确认，不能据此声称技能不存在。格式不符合调用规则的文字保留为普通正文。菜单选择不显示已经加载成功；实际加载由宿主收到重发的用户文本后完成，同名宿主命令不经过执行入口。

已通过本机安装包的真实技能加载钩子验证代表性技能指令。界面测试同时经过现有重发流程、真实 Gateway 和 Host plugin，确认交给宿主的消息仍为用户来源。覆盖重复名称去重、仅用户可调用技能、失效技能、仅模型可调用技能、同名命令、路径、分数和标点边界。注册表和接收方使用隔离替身，不操作真实用户会话。

最终检查还发现并修复了组合粘贴场景：同时粘贴文件引用和技能查询时，文件标签恢复会刷新正在使用的技能菜单；已经关闭的菜单保持关闭，旧候选仍失效。技能选择后的预检取消、确认和失败补发均保留首次固定文本，后续编辑不能改写待补发内容。
