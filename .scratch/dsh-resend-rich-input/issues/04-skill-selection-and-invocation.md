# 04 — 用 / 选择并调用 skill

Type: task
Status: ready-for-agent

**What to build:** 临时输入框输入 / 后可选择当前目标会话允许用户调用的 skill；选择结果保留为可编辑文字，并在重发后交由宿主加载。

**Blocked by:** [03 — 用 @ 引用文件、文件夹与外部路径](03-file-directory-external-references.md)。

- [ ] 复用独立候选菜单，使用宿主按目标会话筛选的 skill 列表，不自行扫描技能目录；菜单不加入其他 slash 命令。
- [ ] 选中后插入可编辑技能名称及正确空白边界，支持句中选择、多个 skill、删除和替换；文件路径、分数不误调用。
- [ ] 菜单键盘和输入法规则与文件选择一致；查询结果可取消，旧结果不插入新草稿。
- [ ] 历史技能已失效、改名或不可供用户调用时提示，但保留并允许原文发送；查询失败不能提示为确定不存在。
- [ ] 同名宿主命令不执行；只有符合调用规则且可供用户调用的 skill 会加载，其他内容提示后作为普通原文发送。
- [ ] 宿主真实技能加载钩子收到重发的用户文本后加载代表性 skill 指令，重复名称按宿主规则去重；不存在或仅模型可调用的 skill 不被伪装成调用成功。
- [ ] 验证菜单到重发、技能加载、失效提示后发送的完整行为，接收与技能注册表可用隔离替身，不操作真实用户会话。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。
