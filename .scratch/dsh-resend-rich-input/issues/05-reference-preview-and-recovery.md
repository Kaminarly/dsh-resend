# 05 — 引用预览与会话变化、失败恢复

Type: task
Status: ready-for-agent

**What to build:** 点击文件或 skill 引用可预览对应资源；在预览、切换会话或预设、重连、多编辑区及失败补发期间，引用仍属于原编辑目标，草稿保留且文件操作不会重复。

**Blocked by:** [04 — 用 / 选择并调用 skill](04-skill-selection-and-invocation.md)。

- [ ] 文件预览按目标会话和完整路径定位，skill 预览按当前目录结果定位，不猜测同名技能文件；目录、外部路径和不可预览资源按宿主能力准确提示。
- [ ] 预览不修改正文、标签、skill 文字、选区或普通草稿，不触发发送；选区编辑、双击或拖选与引用点击兼容。
- [ ] 预览、候选与草稿按会话、编辑区和窗口隔离，普通 Composer 的正文、附件、选区、菜单及撤销历史不受影响。
- [ ] 连接重置、预设变化、目标切换和编辑器销毁取消请求并使相关缓存失效；恢复后按原目标获取最新目录，旧结果不能插入另一条消息或重新打开已关闭编辑器。
- [ ] 文件、目录与多个 skill 混合引用形成唯一固定发送文本；预检期间禁用正文、标签、候选和可改写草稿的操作。
- [ ] 预检取消、清单失效、发送前拒绝和异常均保留本次编辑，并禁止失效目标重发。
- [ ] 文件引用读取重发时的工作文件：选择还原后读取还原内容，选择保留后读取当前内容；新增路径不扩大回滚清单，skill 按调用时可用指令加载。
- [ ] 回退已完成但消息未被接收时，「再次发送」复用原固定文本，不按最新草稿重新转换，不重复回退文件或生成第二个 Rewind point。
- [ ] 用真实浏览器、受控延迟、逆序响应、目标切换、失败与隔离接收替身验证预览零发送、跨会话隔离、文件预检和精确补发；相关回归通过。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。
