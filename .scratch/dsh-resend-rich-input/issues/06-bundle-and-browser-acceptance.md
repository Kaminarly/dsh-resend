# 06 — 交付经过兼容和真实浏览器验收的 Bundle

Type: task
Status: ready-for-agent

**What to build:** 产出包含全部确认能力的可安装 Bundle，并以真实浏览器和隔离宿主验证完整用户流程，明确证据与实际未验证范围。

**Blocked by:** [05 — 引用预览与会话变化、失败恢复](05-reference-preview-and-recovery.md)。

- [ ] 构建、现有语法与宿主兼容检查、相关测试及完整回归通过；打包产物与源代码的行为一致。
- [ ] 真实浏览器中验证历史引用恢复、新文件/目录/外部路径、skill、预览、键盘与输入法、复制粘贴、撤销、预检和失败补发。
- [ ] 浅色、深色与窄窗口下菜单和标签可用，没有横向溢出或遮挡关键按钮；原三行高度和内容伸缩、发送按钮和中文文案保留。
- [ ] 菜单可用键盘选择，焦点与可访问名称正确；浏览器中没有未处理异常，新增控制台错误已解决。
- [ ] 能力缺失与失效 skill 的降级提示、普通草稿隔离、多目标切换通过，不能将替身验证描述为真实模型回复。
- [ ] 交付构建包及完整验证记录；安装插件和向真实用户会话发送消息不自动纳入本任务，按用户授权范围处理。

**依据：** [已确认规格](../spec.md)、[宿主能力研究](../research/host-capabilities.md)与[独立编辑路线](../../../docs/adr/0002-independent-temporary-input.md)。
