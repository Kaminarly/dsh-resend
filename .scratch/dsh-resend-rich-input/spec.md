# 临时输入框文件引用与 skill

Status: accepted

日期：2026-10-12。Q1–Q11 已由用户逐项选择，Q12 已确认整体方案符合要求，研究阶段收口。本轮交付研究与规格，功能尚未实现。

## 用户确认的行为

| 问题 | 已选行为 |
| --- | --- |
| Q1 原引用 | 自动保留原文件引用与 skill 文字，允许新增、删除、替换 |
| Q2 范围 | 文件引用与 skill；其他 slash 命令另行研究 |
| Q3 入口 | `@` 搜索文件，`/` 搜索 skill |
| Q4 显示 | 文件显示可删除标签；skill 保持可编辑 `/名称` |
| Q5 文件内容 | 读取重发时的工作文件，不固定原消息时的内容 |
| Q6 失效 skill | 提示，但允许原文发送 |
| Q7 路线 | 插件实现独立界面，复用宿主能力，不修改 DSH 本体 |
| Q8 查询不可用 | 提示，保留原文和纯文本编辑重发能力 |
| Q9 文件范围 | 文件、文件夹及宿主可搜索的外部路径；排除会话引用 |
| Q10 命令冲突 | 临时框只调用匹配 skill，不执行其他命令；未匹配内容提示后原文发送 |
| Q11 交互 | 菜单 Enter/Tab 选择，关闭后 Enter 重发，Shift+Enter 换行；Escape 先关菜单再退出；中文输入法确认不发送；点击引用预览；取消或失败保留本次编辑 |

## 设计树

```text
临时输入框引用能力
├─ 范围 → 原引用保留 + 新增（Q1）
│  ├─ 类型 → 文件引用 + skill（Q2）
│  ├─ 路径 → 文件、目录、可搜索外部路径（Q9）
│  └─ 内容 → 调用时工作文件（Q5）
├─ 交互 → @、/ 菜单（Q3）
│  ├─ 呈现 → 文件标签 + skill 文字（Q4）
│  └─ 键盘、预览、编辑保留（Q11）
├─ 接入 → 独立编辑器 + 宿主查询 + 文本重发（事实调查、Q7）
│  └─ 命令同名 → skill 语义，不执行宿主命令（Q10）
└─ 异常
   ├─ skill 失效 → 提示且允许原文发送（Q6）
   └─ 搜索不可用 → 保留纯文本能力（Q8）
```

## 状态与内容规则

- 草稿按目标 Session 与用户消息 seq 隔离。普通 Composer 的正文、附件、选区、菜单和撤销历史不因临时编辑而变化。
- 历史文本恢复为文字和文件标签；不把显示文件名当路径，也不把未知文本改写成已确认引用。
- 每个临时编辑器拥有独立候选状态。按当前目标 Session 查询，不使用当前聚焦窗口的另一会话。
- 请求带取消信号；接收结果时核对编辑器、会话、触发词、查询和草稿版本。失效结果既不显示，也不插入内容。
- 发送前一次性导出宿主等价文本，冻结到既有重发请求。预检期间禁用正文、标签和候选操作；取消预检恢复本次编辑。
- 退出临时编辑保留当前页面内本次草稿，再次打开同一有效目标恢复编辑；目标失效后禁止重发。页面刷新后持久化恢复不在本轮承诺范围。
- 重发成功后清理该临时草稿。拒绝或发送异常保留正文和引用；回退已完成但消息未被接收时，沿用既有「再次发送」入口和固定文本，不重复回退或重新序列化。
- 未匹配 `/name` 或查询失败时只作准确提示。宿主可能跳过失效 skill，界面不能把用户选择当作实际成功加载。
- 文件或 skill 预览只打开资源，不改变正文或触发发送。外部路径与目录是否可打开，以宿主资源能力为准；不可预览时给出原因。

## 实施与验收

实施拆分：独立编辑器与文本转换；候选查询与菜单；历史恢复与预览；现有重发接入；兼容检查及浏览器验收。隔离原型先证明编辑器依赖可打包、标签恢复和带空格目录行为，再选择具体编辑器库。

验收必须证明以下行为，不能仅凭构建通过宣布完成：

1. 带文件和多个 skill 的旧消息打开后保留顺序与完整文本；同名不同路径能区分；删除和替换仅影响所选引用。
2. 中文、空格、绝对路径、目录下钻、句中技能和复制粘贴按宿主发送规则表达；目录引用不吞入后续正文。
3. 输入法、菜单 Enter/Tab、Shift+Enter、分层 Escape、撤销、选区编辑和引用预览符合 Q11。
4. 普通草稿已含文字和附件时，临时编辑、预览、取消、重发都不修改普通草稿；多个编辑区、窗口和目标会话互不串状态。
5. 候选延迟、返回逆序、关闭编辑、连接重置、切换预设、接口缺失与失效 skill 均保留草稿，并显示准确提示。
6. 预检取消、恢复/保留文件、发送前拒绝、回退后消息未接收及再次发送均使用同一份最终文本；补发不重复文件操作。
7. 宿主真实 skill 加载钩子收到重发文本后能加载可供用户调用的技能；文件引用保持路径语义，不声称自动上传或已经读取文件。
8. 构建、现有检查、相关回归与真实浏览器交互通过；真实用户会话发送仅在明确授权的实施验证范围内进行。

研究证据及已运行验证见 [研究报告](research/host-capabilities.md)。路线记录见 [ADR](../../docs/adr/0002-independent-temporary-input.md)。
