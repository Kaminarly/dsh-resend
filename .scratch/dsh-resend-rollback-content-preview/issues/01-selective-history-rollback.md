# 01 — 历史面板多选还原与真实结果

Status: ready-for-agent

**要交付：** 用户在历史 Rewind point 的文件回滚面板中勾选要还原的文件，只还原选中集合，并查看准确、可恢复的处理结果。整个回滚点在本次成功处理后结束。

**Blocked by:** 无，可以先开始。

任务已按用户确认发布。依据已确认规格第 1–3、7–10、12–13 节及多选回滚完成边界。

## 验收标准

- [ ] 首次清单默认勾选全部可还原文件，支持全选、取消全选、部分选中和逐文件选择；无法还原成员禁选并显示原因。
- [ ] 正确显示选中还原、用户选择保留和系统无法还原数量；列表控件采用宿主风格，名称、目录、状态及复选框可辨且不互相挤压。
- [ ] 选择 A、未选 B 时，仅改变 A；B 在确认前或执行中发生外部变化，不阻止 A 且保持 B 的当前内容。
- [ ] 选中成员在执行前变化，则整次不开始写入；执行中出现变化则停止后续写入，并报告实际已处理和未处理结果。
- [ ] 成功结果逐文件区分已还原、用户选择保留、系统无法还原；成功后整个回滚点结束，未选文件不可从同一点补还原，刷新或重启后结果准确。
- [ ] 部分失败保存确认的选择身份和每个成员的实际进度；已还原与结果不确定成员不重复执行，失败不伪报成功或自动撤销已还原文件。
- [ ] 零选隐藏还原按钮，关闭仅取消待执行清单，不写成功完成记录，不产生会话变化或生成。
- [ ] 显式选择必须非空、唯一、属于有效清单且可还原；伪造、重复、跨清单或禁选成员被拒绝，不写文件、不消费有效清单。省略选择的旧调用仍按原全量行为处理。
- [ ] 结果与中断记录采用可识别的新版本，旧完成及旧中断数据仍可读取，旧记录不被猜测为用户选择保留。
- [ ] 使用真实临时工作文件验证子集、未选外部修改、执行中断和保存失败；接口、状态持久化、面板交互及既有仅文件行为检查通过。

## 范围边界

本项不提供正文弹窗，不增加分批补还原。重发前的继续、取消和部分失败收尾由 02 接入；两个新功能的综合恢复由 04 核验。
