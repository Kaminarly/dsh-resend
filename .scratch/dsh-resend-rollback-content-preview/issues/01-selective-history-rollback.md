**Blocked by:** 无，可以先开始。

## 验收标准

- [x] 首次清单默认勾选全部可还原文件，支持全选、取消全选、部分选中和逐文件选择；无法还原成员禁选并显示原因。
- [x] 正确显示选中还原、用户选择保留和系统无法还原数量；列表控件采用宿主风格，名称、目录、状态及复选框可辨且不互相挤压。
- [x] 选择 A、未选 B 时，仅改变 A；B 在确认前或执行中发生外部变化，不阻止 A 且保持 B 的当前内容。
- [x] 选中成员在执行前变化，则整次不开始写入；执行中出现变化则停止后续写入，并报告实际已处理和未处理结果。
- [x] 成功结果逐文件区分已还原、用户选择保留、系统无法还原；成功后整个回滚点结束，未选文件不可从同一点补还原，刷新或重启后结果准确。
- [x] 部分失败保存确认的选择身份和每个成员的实际进度；已还原与结果不确定成员不重复执行，失败不伪报成功或自动撤销已还原文件。
- [x] 零选隐藏还原按钮，关闭仅取消待执行清单，不写成功完成记录，不产生会话变化或生成。
- [x] 显式选择必须非空、唯一、属于有效清单且可还原；伪造、重复、跨清单或禁选成员被拒绝，不写文件、不消费有效清单。省略选择的旧调用仍按原全量行为处理。
- [x] 结果与中断记录采用可识别的新版本，旧完成及旧中断数据仍可读取，旧记录不被猜测为用户选择保留。
- [x] 使用真实临时工作文件验证子集、未选外部修改、执行中断和保存失败；接口、状态持久化、面板交互及既有仅文件行为检查通过。

## 范围边界

本项不提供正文弹窗，不增加分批补还原。重发前的继续、取消和部分失败收尾由 02 接入；两个新功能的综合恢复由 04 核验。

## Answer

2026-10-13：已完成历史面板多选还原与真实结果。

接口契约：`rollback` 请求新增可选 `selected`；结果文件 action 扩展为 `restore / refuse / kept / restored`，preview 值可携带中断后记录的 `selected` 选择身份（`src/typert.js`，两个 descriptor face 同步再生）。省略 `selected` 的调用保持原全量还原行为与旧记录格式。

宿主执行（`src/file-rollback.js`）：选中集合在消费计划之前校验（非空、唯一、属于该计划且可还原），无效请求返回 `invalid-selection`，不写文件、不消费计划；执行只核验、只写入选中集合；中断日志 v2 保存选择身份与逐成员真实进度，已还原/结果不确定成员（包括其他窗口持有的过期计划）永不重复写回；成功后整个回滚点以带版本完成记录（`{kind:'file-rollback-result', version:2}`）终结，逐文件区分已还原/用户选择保留/系统无法还原；v1 旧日志与旧完成记录按原语义读取、重存保持旧拼写，不猜测为用户保留。已提交但校验失败的成员不升级为完成——部分失败的回滚点保持打开，不伪报成功。
