# 02 — 重发前按选择处理文件并继续

Status: ready-for-agent

**要交付：** 编辑重发、重新生成前，用户可以选择部分文件还原，文件决定完成后再续接会话。发生部分失败时先停下，并允许明确保留剩余文件后继续。

**Blocked by:** 01 — 历史面板多选还原与真实结果。

任务已按用户确认发布。依据已确认规格第 1、3、7–10、12–13 节。

## 验收标准

- [ ] 编辑重发和重新生成共用选择规则，默认全选；「还原 N 个文件并继续」中的数量取实际选中集合，不能仍按全部可还原成员计算。
- [ ] 只恢复选中成员，真实结果保存后才执行会话续接和发送；用户未选文件准确记录为保留，不被报告为已还原。
- [ ] 「保留当前文件并继续」忽略勾选，保留尚未处理文件并沿用正常保留流程；零选隐藏还原按钮，仍可保留继续或取消。
- [ ] 无文件变化时仍直接发送，无空面板；取消保留编辑草稿，不产生发送或新的文件处理。
- [ ] 还原中禁止重复确认、修改勾选或重新查看正文；重复点击和另一选择不得启动第二次处理。
- [ ] A 已还原、B 失败、C 未选时停止自动生成，显示真实结果；允许重新检查后调整剩余选择，不重复处理 A，不自动选中 C。
- [ ] 用户取消全部剩余勾选后，可使用「保留剩余文件并继续」；保存真实结果与保留决定后结束回滚点再生成，保存失败则停止，结果不确定的文件继续记录为不确定。
- [ ] 部分还原后取消重发不自动恢复已还原文件，不终结未完成回滚点；界面清楚说明已经发生的处理。
- [ ] 文件已成功处理而会话续接、发送或其他步骤失败时，重试不重复还原、不扩大集合，不把用户保留文件报告为已还原。
- [ ] 主要还原、次要保留、弱化取消的操作层级符合宿主风格；两个入口都保持原有中文及各自用途。
- [ ] 使用真实工作文件和可检查的生成接收替身验证文件内容、保存结果、会话操作及发送先后顺序；覆盖子集、零选、取消、部分失败收尾和发送失败。

## 范围边界

本项复用 01 的执行与结果能力，不要求内容预览先完成。内容弹窗由 03 独立交付，完整刷新和跨窗口一致性由 04 合并核验。
