# 03 — 两个入口的受限内容预览弹窗

Status: ready-for-agent

**要交付：** 用户从历史面板或重发前面板点击「查看差异」，在独立大弹窗中查看当前内容到还原后内容的差异，并安全返回原面板。无法展示正文时明确降级，仍保留文件原有还原资格。

**Blocked by:** 无，可以先开始。

任务已按用户确认发布。依据已确认规格第 2、4–6、10–13 节。

## 验收标准

- [ ] 两个入口均只为待执行、可还原的清单成员提供正文查看；无法还原文件显示原因，已完成结果不提供正文入口。
- [ ] 正文按需只读获取，校验有效清单、会话归属和成员身份；不能读取任意路径或私有快照地址，不暴露存储位置，不消费清单、不写文件、不生成。
- [ ] 差异方向为当前内容到工作前保存内容；连续多次改写展示合并净差异，不从 Git HEAD 获取还原目标。
- [ ] 大弹窗采用宿主控件、主题和代码字体，以约 960 像素为桌面布局基准；完整路径、方向、关闭入口可见，正文占主要空间且独立滚动。
- [ ] 同列差异具有行号、必要上下文、删除／恢复标记与图例；查看不改变勾选，弹窗没有勾选或执行入口。清单多选先交付时也不应依赖勾选才能查看。
- [ ] 删除新增文件、删除新增空文件、还原为空文件及不存在状态均明确区分；新增文件在列表和弹窗显示删除提示，不再添加第二次确认。
- [ ] 中文、BOM、CRLF/LF、末尾换行和纯格式差异正确展示或说明；正文展示不改变最终恢复字节，按文本显示且不执行 HTML 或其他内容。
- [ ] 合计超过 3 MiB、任一版本超过 10,000 行、任一单行超过 20,000 Unicode 码点、非文本或计算受限时明确降级；检查发生在正文传输前，不显示截断片段，仍允许原本可还原的文件被选择。
- [ ] 分别测试恰好等于及超过阈值；空内容、末尾行结束符、不存在的一侧和 BOM 的计数符合规格。
- [ ] 加载、正常差异、无法预览、读取失败、清单失效有明确状态；普通读取失败可重试，不被误报为无法还原，不自行取消选择。
- [ ] 关闭按钮、遮罩和 Escape 只关闭正文；Tab 属于最前景弹窗，底层重发弹窗不被一起取消，关闭后返回原位置。取消、执行、会话切换及失效后旧响应不能重新打开弹窗。
- [ ] 验证恶意读取、非文本、长行和超限内容；使用真实宿主控件验证浅色、深色、窄窗口和弹窗叠加，确保文本和差异不会撑宽页面。

## 范围边界

本项独立使用现有有效清单，不等待多选能力，因此与 01 无功能依赖。内容与后续多选集成时，仍遵守查看和勾选分离；完整变化与恢复组合由 04 核验。
