# 03 — 两个入口的受限内容预览弹窗

Status: resolved

**要交付：** 用户从历史面板或重发前面板点击「查看差异」，在独立大弹窗中查看当前内容到还原后内容的差异，并安全返回原面板。无法展示正文时明确降级，仍保留文件原有还原资格。

**Blocked by:** 无，可以先开始。

## 验收标准

- [x] 两个入口均只为待执行、可还原的清单成员提供正文查看；无法还原文件显示原因，已完成结果不提供正文入口。
- [x] 正文按需只读获取，校验有效清单、会话归属和成员身份；不能读取任意路径或私有快照地址，不暴露存储位置，不消费清单、不写文件、不生成。
- [x] 差异方向为当前内容到工作前保存内容；连续多次改写展示合并净差异，不从 Git HEAD 获取还原目标。
- [x] 大弹窗采用宿主控件、主题和代码字体，以约 960 像素为桌面布局基准；完整路径、方向、关闭入口可见，正文占主要空间且独立滚动。
- [x] 同列差异具有行号、必要上下文、删除／恢复标记与图例；查看不改变勾选，弹窗没有勾选或执行入口。清单多选先交付时也不应依赖勾选才能查看。
- [x] 删除新增文件、删除新增空文件、还原为空文件及不存在状态均明确区分；新增文件在列表和弹窗显示删除提示，不再添加第二次确认。
- [x] 中文、BOM、CRLF/LF、末尾换行和纯格式差异正确展示或说明；正文展示不改变最终恢复字节，按文本显示且不执行 HTML 或其他内容。
- [x] 合计超过 3 MiB、任一版本超过 10,000 行、任一单行超过 20,000 Unicode 码点、非文本或计算受限时明确降级；检查发生在正文传输前，不显示截断片段，仍允许原本可还原的文件被选择。
- [x] 分别测试恰好等于及超过阈值；空内容、末尾行结束符、不存在的一侧和 BOM 的计数符合规格。
- [x] 加载、正常差异、无法预览、读取失败、清单失效有明确状态；普通读取失败可重试，不被误报为无法还原，不自行取消选择。
- [x] 关闭按钮、遮罩和 Escape 只关闭正文；Tab 属于最前景弹窗，底层重发弹窗不被一起取消，关闭后返回原位置。取消、执行、会话切换及失效后旧响应不能重新打开弹窗。
- [x] 验证恶意读取、非文本、长行和超限内容；使用真实宿主控件验证浅色、深色、窄窗口和弹窗叠加，确保文本和差异不会撑宽页面。

## 范围边界

本项独立使用现有有效清单，不等待多选能力，因此与 01 无功能依赖。内容与后续多选集成时，仍遵守查看和勾选分离；完整变化与恢复组合由 04 核验。

## Answer

2026-10-14：已完成两个入口的受限内容预览弹窗。

历史面板和重发前面板均提供独立的「查看差异」入口，只面向有效清单中待执行、可还原的成员；查看未勾选文件不会改变选择，已完成结果和无法还原成员不提供正文入口。正文接口分别校验历史计划与前置计划的归属、会话、成员和当前文件内容，复用现有路径与私有存储保护；读取不消费计划，不写工作文件或会话记录，不触发生成，不返回私有快照地址。

差异采用当前内容到工作前保存内容的方向，展示连续改写的合并净差异。展示前检查两个版本原始字节数合计、任一版本行数、任一单行 Unicode 码点数、UTF-8 与控制字符，以及差异计算资源限制；超限时只返回原因、大小和处理动作，不传输截断正文，保留原有还原资格。删除新增文件、新增空文件、还原为空文件和文件不存在分别呈报；BOM、行结束符、末尾换行均有说明，实际恢复仍使用原始保存字节。

弹窗复用宿主 Modal、Button、主题和代码字体，桌面以 960 像素为基准，完整路径、方向及关闭入口固定可见，正文独立滚动。差异带两侧行号、上下文、删除／恢复符号及图例，文件内容只作为文本显示。关闭按钮、遮罩和 Escape 只关闭正文并返回原查看按钮；Tab 保持在前景弹窗内。清单变化、取消、执行、会话切换、连接重置、清理和组件释放会关闭或退役对应预览，迟到响应不会重新打开正文。
