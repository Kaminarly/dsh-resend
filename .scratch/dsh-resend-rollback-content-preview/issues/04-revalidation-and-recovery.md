## 验收标准

- [x] 两个入口重新检查时按文件身份保留原选择；首次清单以外不默认全选，新增及无法还原成员不自动选中。
- [x] 查看未选文件仍核验当前内容；该文件变化时旧差异不能再作为当前正文显示，但不能因此扩大或执行选择，未选变化也不阻止选中集合处理。
- [x] 选中文件变化、清单替换、取消、执行、清理或会话释放后，关闭或失效正文并提示重新检查；不静默改用新清单执行。
- [x] 部分失败后，A 已还原、B 已选未完成、C 未选的状态经过重新检查、刷新、重启和另一窗口读取仍准确；A 不重复写入、B 保持选中、C 保持未选。
- [x] 已执行选择与实际进度依据保存结果恢复；结果不确定成员不能再次选择，也不被显示为成功或未处理。
- [x] 读取或清单响应逆序、关闭后迟到、切换会话后迟到、组件释放后迟到均不能覆盖新状态或重新创建弹窗。
- [x] 部分失败后的保留继续、正常保留继续、取消及历史零选关闭保持各自完成语义；错误恢复不能把关闭转换为完成。
- [x] 助手忙碌、会话变化、清理及其他窗口使操作失效时，停止不再安全的操作，保留真实结果，并提供可用的重新检查、保留或取消路径。
- [x] 两层弹窗叠加、清单更新移除原文件行、结果状态变化时，Escape、Tab 和焦点返回仍正确，不跳到已失效控件。
- [x] 用真实文件、独立窗口状态及重启读取验证上述组合；旧完成及旧中断记录回归通过，保存失败和文件成功后的发送失败不导致重复处理。

## 范围边界

不引入时间自动过期、自动扩选或分批补还原；不新增预览能力或绕过前置任务的安全边界。

## Answer

2026-10-14：已完成重新检查与跨窗口恢复选择。

两个入口仅在首次清单默认全选；重新检查按文件身份保留勾选，新增或无法还原成员不自动选中。保存记录中的执行选择优先恢复，后续手动调整仍可保留。历史面板按会话和回滚点隔离状态，关闭、切换会话或组件释放后的迟到响应不会覆盖新面板。清单替换、取消、执行、清理和连接重置会关闭正文或使清单失效；窗口重新获得焦点时再次核验正在查看的文件，读取期间移除旧差异，查看未选文件不改变选择。

重发前清单保存原操作的关联信息；再次进入相同操作时，沿用原始文件记录和已经保存的真实进度，避免因重新计算清单而丢失部分失败结果。已还原和结果不确定成员保持禁选，原未选成员保持未选。另一窗口的执行进度发生变化后，旧清单不能继续执行，必须重新检查。会话释放后的最终写入检查停止后续文件处理，已发生的结果仍保存；部分失败后保留剩余文件成功、但撤回旧对话失败时，继续呈报真实的已还原与保留结果，重试不重复处理文件。取消和历史零选关闭不被转换为完成。

两层弹窗的键盘操作包含复选框；正文入口因清单更新而消失时，焦点返回仍有效的面板，正向或反向 Tab 保持在当前弹窗内。原有中文文案得到保留，未增加自动过期或分批补还原能力。
