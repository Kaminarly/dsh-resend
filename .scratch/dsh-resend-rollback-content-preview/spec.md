# 文件回滚内容预览与多选还原

Status: ready-for-agent

日期：2026-10-13。用户已确认全部产品决定、美观实用且匹配 DSH Desktop 的样式要求，以及整体规格；访谈结束。本规格已定稿，用于后续实现和验收，功能尚未实现。

## 1. 目标与范围

用户在确认文件回滚之前，可以查看「当前内容 → 还原后内容」的差异，并选择本次要还原的文件。界面必须准确区分实际已还原、用户选择保留和系统无法还原。

覆盖两个入口：

- 编辑重发、重新生成之前的文件处理面板。选中文件处理完成后，再执行既有会话续接与发送流程。
- 历史 Rewind point 的文件回滚面板。只处理文件，不改变会话，也不生成回复。

不增加已完成结果的正文查看、无法还原文件的历史正文查看、文件编辑、逐行还原、同一回滚点分批补还原、任意文件读取或额外的文件变更捕获入口。无文件变化时，仍跳过前置面板直接发送。

## 2. 术语与内容方向

沿用 [CONTEXT.md](../../CONTEXT.md) 中的文件回滚、文件回滚预览、文件回滚内容预览、选中还原文件和用户选择保留。

- 当前内容：有效回滚清单创建并核验时的工作文件内容。内容读取及执行仍需核验其有效性，不将历史快照直接冒充最新工作文件。
- 还原后内容：这次被回滚的工作开始之前保存的内容，包含当时已有的用户修改。不是 Git HEAD，也不是仓库最初版本。
- 差异中的删除行：回滚将从当前文件移除的行。
- 差异中的恢复行：回滚将写回文件的行。
- 同一文件多次被改写时，展示这次回滚的合并净差异，不按每次工具调用拆分。

预览只读，不写文件、不取消清单、不触发生成。查看差异不等于勾选文件。

## 3. 文件多选列表

首次创建待确认清单时，默认勾选全部可还原文件；无法还原的文件显示原因，禁止勾选，不提供正文预览入口。提供「全选／取消全选」及逐行复选框；批量选择只影响可还原文件。

每行保留文件图标、名称、目录、处理状态；增加独立的「查看差异」按钮。复选框、文件信息和查看按钮之间不能发生隐式联动。文件是否勾选，不影响其在符合条件时查看差异。

列表与弹窗的视觉设计均须满足第 12 节，不能仅以功能可用作为完成标准。

列表同时展示选中还原数量、用户选择保留数量、无法还原数量。选择变化只改变本次执行集合，不改变文件本身的可还原资格。

若仍存在可还原文件，批量复选状态分别表达全选、部分选中和未选。没有可还原文件时，批量选择不可用。执行顺序采用清单顺序，不由勾选顺序决定。

## 4. 内容预览弹窗

点击「查看差异」后打开独立大弹窗，每次展示一个文件。标题区包含文件名称、完整路径、当前内容到还原后内容的方向及处理动作。正文采用同列差异，有行号、删除／恢复标记和必要上下文，不能只用颜色表达含义。

弹窗只负责查看，不提供勾选、还原或生成按钮。最终文件选择与执行均在原面板完成。窗口宽度受视口约束，窄窗口使用可用宽度，正文独立滚动；长行可以在正文内横向滚动，不能撑宽宿主页面。适配宿主浅色和深色主题。

关闭按钮、点击遮罩、Escape 只关闭内容预览，保留清单和勾选，焦点返回原查看按钮；如果按钮已移除，则返回文件面板。弹窗打开时，Tab 在最前景弹窗内移动，底层面板不可操作。底层本身是重发前置弹窗时，Escape 不得同时取消重发。

状态必须区分正在读取、正常差异、内容不适合预览、读取失败、清单失效。读取失败支持重试和关闭；关闭后晚到的响应不能重新打开弹窗。旧清单失效、切换会话、取消或开始执行时关闭内容弹窗并释放对应缓存。

文件内容作为文本展示，不解释为 HTML、Markdown 页面或可执行内容。

## 5. 文件删除、空文件和内容保真

助手新增文件在回滚时会删除。列表和弹窗必须显示「还原后将删除此文件」，差异显示全部当前内容被删除。新增空文件也显示删除动作，不能因为没有行差异而隐藏操作。

还原为空文件显示「还原后为空文件」，与「还原后文件不存在」区别处理。现有可核验记录若表达恢复不存在的文件，应展示创建动作；本需求不扩展助手删除文件的捕获能力。

恢复内容必须与保存的原始字节一致。中文、BOM、CRLF/LF、末尾换行和仅换行差异不得因展示处理而被写回不同内容。正文看起来相同但字节不同，应显示格式差异提示，不能误报为无需还原。

删除新增文件不增加第二次确认弹窗；原面板显示删除提示，使用本次统一确认。

## 6. 正文预览限制

以下任一条件成立，显示降级说明、可获得的文件大小和处理动作，不展示截断内容，也不影响原本可还原的文件被选择：

| 条件 | 规则 |
|---|---|
| 内容大小 | 当前内容与还原后内容的原始字节数合计 **超过 3 MiB**，即超过 3,145,728 字节 |
| 行数 | 任一版本超过 10,000 行；空内容计 0 行，末尾行结束符不额外计一个空行 |
| 单行长度 | 任一行超过 20,000 个 Unicode 码点，不将行结束符计入长度 |
| 非文本 | 无法严格解码为 UTF-8，或包含 NUL 等不适合文本展示的内容 |
| 差异计算受限 | 无法在受限资源下完成差异计算时显示明确说明，不让页面持续卡住 |

阈值恰好相等时不因该阈值降级，仍需检查其他限制。文件不存在的一侧字节数和行数计 0；BOM 计入原始字节数。

降级只描述无法展示内容，不得标为无法还原。缺少快照、工作文件内容变化、路径不安全等真正无法还原则按既有保护规则处理，禁止勾选。

## 7. 按钮与确认

| 入口及状态 | 操作与含义 |
|---|---|
| 重发前，选中 N > 0 | 「还原 N 个文件并继续」：处理选中集合，保存实际结果，再执行既有重发流程 |
| 重发前，任意勾选 | 「保留当前文件并继续」：忽略当前勾选，保留全部尚未处理文件并继续 |
| 重发前，零选 | 隐藏还原按钮，保留继续和取消操作 |
| 重发前，取消 | 「取消重发」：取消待执行操作，保留编辑草稿和已有文件处理结果 |
| 历史面板，选中 N > 0 | 「还原 N 个文件」：只处理选中集合 |
| 历史面板，零选 | 仅提供关闭；可以查看可预览文件，关闭不记为回滚完成 |
| 已完成结果 | 只查看实际结果、收起；无勾选、正文预览及重复还原入口 |

执行前提示：「仅还原选中的文件；本次完成后，未选文件将保留，不能从此回滚点再次还原。」

执行中禁止重复确认、修改勾选或打开正文预览。普通正文读取不等于执行；读取结束前仍可以关闭预览，不要求用户查看每个文件才允许还原。

## 8. 失效、部分失败与重试

### 内容或清单变化

执行只核验选中集合。未选文件变化不阻止选中文件还原，但查看这个未选文件的差异时仍需核验当前内容，不能显示过时的「当前内容」。

任一选中文件在执行前变化，本次不开始写入；清除旧差异并提示重新检查，不静默换成新目标后执行。会话变化、助手忙碌、快照被清理等原有保护继续生效。

重新检查后，按文件身份保留原有选择；新增文件、已无法还原文件不自动选中。只有首次清单采用默认全选。内容读取失败若不涉及清单失效，只影响正文展示，不自行取消勾选。

### 部分写入失败

例如 A 已还原、B 失败、C 未选：停止后续还原和自动生成，报告 A 的实际结果、B 的失败原因和 C 的保留选择。不得声称全部成功，也不得自动撤销 A。

重新检查后，A 不可重复还原；B 若仍符合条件，保持选中；C 保持未选。允许用户调整剩余可还原文件，再确认。已发生执行的选择与进度必须在刷新、重启和另一窗口读取后正确恢复，不能重新默认全选。结果不确定的文件禁止重复还原，并提示检查。

部分失败不将整个回滚点标为成功完成。选择「取消重发」或关闭历史面板不会自动撤销已还原文件，也不将未完成集合标为成功处理。

### 文件成功后其他步骤失败

实际文件结果已经保存，而会话续接或发送失败时，继续既有重试流程；不得再执行文件还原，不允许重新扩大已确认的集合。结果保存失败时，不开始生成，并避免把未知结果当作已确认成功。

### 部分失败后的零选收尾

A 已还原、B 尚未完成时，用户取消所有剩余勾选，可选择「保留剩余文件并继续」。保存 A 的真实结果及尚未处理文件的保留决定后，结束该回滚点并继续生成；保存失败则停止。结果不确定的文件保留真实状态，不得改写为已还原或未处理。取消重发不终结；历史面板零选关闭同样不终结。

## 9. 完成记录与兼容

本次选中集合成功处理并保存结果后，整个回滚点永久完成；未选文件不能从同一回滚点补还原。分别持久保存实际已还原、用户选择保留和系统无法还原，及其必要原因。计数与显示只能使用逐文件真实结果，不能将完成清单中原本可还原的成员全部推断为已还原。

该边界见 [ADR-0002](../../docs/adr/0002-selective-rollback-finalizes-point.md)。进度应保存用户确认的选择身份、实际结果与未处理状态。新记录必须有可识别的版本，并兼容旧完成结果和旧中断记录；旧数据不应被猜测成用户主动保留。

单纯查看、取消、历史面板零选关闭均不写入成功完成结果。正常重发前「保留当前文件并继续」沿用现有保留流程，不冒充发生过文件还原。

## 10. 读取与执行边界

- 内容按需读取，绑定有效计划、所属会话及清单成员；前置计划与历史计划分别校验各自归属。
- 不开放任意路径或私有快照地址读取；只向前端返回预览必需的正文及状态，不暴露存储位置。
- 读取不得消费计划、改变选择或写入 Session log。关闭、执行、取消、清理、会话释放及重启后，失效计划不能继续读取。
- 正文读取和文件恢复复用现有工作目录、链接及私有存储保护。展示资源限制也在内容传输前检查，不能只由前端截断。
- 执行必须校验用户选择：成员唯一、属于该有效清单、可还原且非空。拒绝伪造、重复、跨计划和无法还原成员；无效请求不写文件、不消费合法计划。
- 不携带选择的旧调用保留原全量还原行为；新版界面始终显式传递选中集合。显式空集合不能当成省略选择，也不能被视为成功还原。
- 差异内容不另存到完成结果或中断记录，不增加长期正文副本。

## 11. 实现接入与依据

可行性和现有验证见 [research.md](research.md)，用户逐轮决定见 [decisions.md](decisions.md)。以下为实现接入位置，不要求用户选择内部结构：

| 文件 | 需要处理的职责 |
|---|---|
| `src/file-rollback-preview.js` | 多选状态、真实数量、正文弹窗、两个入口、最前景键盘行为 |
| `src/ui.js`、`src/client.js` | 弹窗与列表样式、宿主主题、原有中文及对应英文文案 |
| `src/resend-operations.js` | 传递选中集合、按需正文读取、失效与迟到响应处理 |
| `src/typert.js` | 严格内容读取和选择契约、前置及历史返回结构一致性 |
| `src/file-rollback.js` | 只读取清单成员、选中子集核验与执行、真实结果及选择持久化 |
| `src/resend.js` | 前置计划传递选择、恢复后失败报告、保留与继续规则 |
| `src/file-versions.js`、`src/rollback-files.js` | 沿用快照、当前内容核验及安全读写边界 |

优先复用本地宿主 `Modal`、`DiffBlock` 和弹窗层级能力；复用前必须验证实际交付能力。差异组件的字符串输入不能将文件不存在偷换为空文件。新增功能时保留原有中文和无关工作区改动。

## 12. 视觉设计与样式要求

### 整体原则

设计须美观、实用，尽量匹配 DSH Desktop 的现有界面。延续截图中回滚面板的简洁布局，以清晰的层级、适度的留白、对齐的控件和稳定的阅读区域体现品质。内容与文件决策是视觉重点，装饰不得挤占正文或增加理解成本。

优先复用宿主的按钮、复选框、文件图标、弹窗和差异展示控件。基础颜色、字体、圆角、阴影、遮罩及交互反馈跟随宿主主题；不另建品牌色、字体或图标体系，不引入与宿主风格无关的渐变、霓虹、强玻璃效果、大面积高饱和背景和夸张动效。

以下设计尺寸为本功能的布局基准；宿主字体缩放或安全边距要求优先，不能为维持固定尺寸牺牲可读性。

### 文件列表与操作层级

- 延续标题、数量摘要、文件列表、底部操作四层结构。名称为主要信息，目录和说明为次要信息，文件状态及查看入口有稳定位置。
- 桌面文件行采用「复选框 → 文件图标 → 名称与目录 → 状态 → 查看差异」顺序，基线对齐；保持 12–16 像素左右的行内留白，不把每个文件另做成厚重卡片。
- 勾选状态以复选框为主，可辅以轻微主题底色；查看按钮不使用主要填充样式，避免与最终还原按钮争夺注意力。
- 每个文件面板只突出一个主要动作。还原采用宿主主要按钮样式，保留采用次要样式，取消或关闭采用弱化样式；仍保持所有操作清晰可见。
- 用户主动保留采用中性文字；系统无法还原采用警告文字与明确原因；已还原采用成功状态。不能把「用户选择保留」显示为错误。
- 长路径、同名文件和长错误原因应有清晰的换行或展开方式；不能仅靠悬停提示才能确认对象。增加内容时避免推挤复选框和查看按钮。

### 弹窗与正文空间

- 采用宿主居中弹窗、背景分层、圆角、轻阴影和遮罩。内容预览位于最前景；叠加前置弹窗时避免重复加深遮罩或重复模糊，使层次清楚。
- 常规桌面预览弹窗宽度以约 960 像素为基准，受视口和宿主安全边距约束；不能沿用普通确认弹窗约 380 像素的窄正文空间。
- 弹窗不超过宿主可用高度。标题、路径、方向说明及关闭入口保持可见，差异正文占主要空间并独立滚动；不能让整个弹窗滚出视口。
- 标题使用宿主标题层级，完整路径可换行。说明文字与标题保持层次，不使用过大的标题或密集徽标。
- 正文采用宿主代码字体与适当行高；行号弱化，删除／恢复标记与代码对齐。充分利用弹窗高度，不将主体默认压缩成只能看十几行的小卡片。
- 无变化上下文可以明确折叠并提供展开操作，但不能隐去差异行或把折叠显示为完整正文；正文超限仍遵守第 6 节的整体降级规则。
- 加载、无法预览和错误状态沿用同一正文区域与间距，说明原因和下一步；避免出现多层嵌套卡片、巨大空白或读取完成后明显跳动。

### 主题、文字与差异配色

使用宿主公开的主题变量，分别适配浅色和深色。颜色不能只凭截图固定为某个色值，字体不能另行下载或改变宿主字号偏好。

| 视觉用途 | 本地宿主已提供的依据 |
|---|---|
| 面板及弹窗背景 | `--dsw-alias-bg-layer-1`、`--dsw-alias-bg-layer-2` |
| 主要／次要文字 | `--dsw-alias-label-primary`、`--dsw-alias-label-secondary` |
| 分隔线与悬停 | `--dsw-alias-border-l4`、`--dsw-alias-interactive-bg-hover` |
| 主要按钮 | 宿主 `Button` 的主要样式及 `--dsw-alias-button-primary-fill` |
| 删除行 | `--dsw-alias-code-diff-deleted`、`--dsw-alias-state-error-primary` |
| 恢复行 | `--dsw-alias-code-diff-added`、`--dsw-alias-state-success-primary` |
| 弹窗圆角、阴影、遮罩 | `--dsw-radius-panel`、`--dsw-elevation-prominent`、`--dsw-alias-bg-mask-1` |
| 代码字体 | `--dsw-font-markdown-code-block` |

差异采用宿主的柔和底色和明确行标记；图例固定解释「− 回滚将删除」与「+ 回滚将恢复」，避免用户误解为助手刚执行的修改。删除、恢复、警告、成功都须同时有文字或符号，不依赖颜色识别。

普通可见文字以至少 4.5:1 的对比度为目标；次要路径、行号、边框和按钮状态在两种主题下仍须可辨。若宿主变量不能满足可读性，应选用更合适的宿主语义层级，不另建一套随意配色。

### 响应布局与交互反馈

- 在 375、768、1024、1440 像素视口验证。窄窗口减少横向留白，文件状态和查看按钮可换行；不缩小文字或隐藏必要状态来维持桌面列布局。
- 长行横向滚动限定在代码区域；路径和普通说明允许换行，宿主页面不得出现由本功能导致的横向溢出。
- 默认、悬停、按下、选中、禁用、正在处理、键盘焦点均应清楚且一致。悬停不改变控件尺寸或导致行跳动。
- 复选框的标签区可扩大点击范围，但不得把查看按钮包含在切换勾选的区域；触屏或粗指针条件下，主要点击区域宜达到 44 × 44 像素。
- 焦点反馈使用宿主样式；图标按钮有文字说明或可访问名称，键盘顺序与视觉顺序一致。
- 过渡沿用宿主时长，以轻微颜色或透明度变化为主；遵守减少动态效果设置，不添加弹跳、缩放或长时间入场动画。

### 视觉验收方式

实现时使用实际 DSH Desktop 控件、字体和主题进行浏览器验证，分别保存浅色／深色桌面和 375 像素窄窗口截图。另验证长路径、同名文件、混合处理状态、全选／部分选中／零选、长差异、加载／降级／错误和弹窗叠加场景。

对照宿主原生弹窗与当前回滚面板检查字体、按钮、背景、圆角、阴影、间距和图标是否协调。不存在重叠、裁切、正文空间不足、操作难辨、状态仅靠颜色或明显布局跳动，才算满足美观实用要求。

## 13. 验收标准

| 场景 | 预期结果 |
|---|---|
| 两个入口首次打开 | 默认选中全部可还原文件，系统无法还原文件禁选且显示原因 |
| 查看未勾选文件 | 弹窗展示差异，不自动勾选、不写文件、不生成 |
| 子集还原 | A 选中、B 未选；只改变 A，结果正确记录 B 为用户选择保留 |
| 未选文件变化 | B 的外部修改不阻止 A；B 内容维持最新外部修改 |
| 选中文件变化 | 执行前 A 变化则未写入任何选中文件，要求重新检查 |
| 重新检查 | 保持原选择，新文件不自动选中，无法还原文件被移出选择，旧弹窗内容失效 |
| 零选 | 重发前保留继续仍可用；历史面板关闭不记完成；空执行请求被拒绝 |
| 新增／空文件 | 明确显示删除新增文件；新增空文件的删除动作也可见；还原为空文件区别展示 |
| 中文与格式 | 正向说明为当前到还原后，恢复字节与快照一致，中文/BOM/换行及末尾换行无损 |
| 大小边界 | 3 MiB、10,000 行、20,000 字符分别测试恰好等于和超出；超限不展示截断正文，仍可还原 |
| 非文本／计算受限 | 显示降级原因，不能导致正文执行或页面持续卡住 |
| 弹窗与键盘 | 关闭、遮罩、Escape 只关预览；Tab 不落到底层；关闭后焦点返回原位置 |
| 窄窗口和主题 | 375 像素视口及浅色／深色均可操作，页面没有被内容撑宽 |
| 宿主风格一致 | 使用实际宿主控件与主题，按钮、字体、圆角、阴影、图标协调，无另建品牌视觉 |
| 列表与操作层级 | 复选框、路径、状态、查看入口清晰对齐；只有还原作为主要动作，保留状态不被标为错误 |
| 弹窗阅读空间 | 桌面为大弹窗，标题与关闭入口可见，正文占主要空间；无狭窄正文、多层嵌套和明显跳动 |
| 差异辨识与可用性 | 删除／恢复有图例及符号，颜色对比可读；键盘焦点清晰，主题和字体缩放下仍能阅读 |
| 视觉证据 | 按第 12 节检查多尺寸和异常状态，保存实际宿主浅色／深色及窄窗口截图 |
| 无快照／外部变化 | 显示真正无法还原原因，禁选，不能与仅无法预览混淆 |
| 部分失败 | A 成功、B 失败、C 未选；停止生成；重试保持选择且 A 不重复还原 |
| 部分失败后保留继续 | 取消剩余勾选后，保存真实结果与保留决定，结束该回滚点并继续生成；保存失败不生成；未知结果不伪报 |
| 刷新／重启／跨窗口 | 已执行的选择与进度正确恢复，未选文件不变为默认选中，未知结果不重复执行 |
| 完成后再次打开 | 只显示持久化真实结果，不能预览正文或从同一回滚点补还原 |
| 保存／发送失败 | 停止或按既有续接流程重试，不重复还原，不误报用户保留文件 |
| 伪造内容读取或选择 | 任意路径、跨会话、跨计划、重复成员、拒绝成员均被拦截，无文件和生成副作用 |
| 失效与迟到响应 | 取消、清理、关闭、切换会话后旧正文不能重新出现或覆盖新预览 |
| 兼容与既有流程 | 旧完成／中断记录可读；无改动直接发送；取消保留草稿；历史入口不生成回复 |

实现交付前运行相关真实文件、严格契约、前置流程和界面测试，并使用实际宿主控件进行浏览器验证；完成仓库要求的构建与检查。本次调查已运行的检查只能作为现有机制依据，不替代新增功能验收。
