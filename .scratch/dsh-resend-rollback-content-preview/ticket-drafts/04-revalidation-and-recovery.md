# 04 — 重新检查与跨窗口恢复选择

Status: needs-triage

**要交付：** 多选和正文预览同时存在时，文件变化、清单失效、部分失败、刷新、重启及另一窗口操作都不会扩大用户选择、重复还原或显示过时正文。

**Blocked by:** 02 — 重发前按选择处理文件并继续；03 — 两个入口的受限内容预览弹窗。

草案尚未发布。依据已确认规格第 4、7–10、12–13 节；基本安全执行、结果保存和正文限制已由前置任务交付，本项完成恢复组合与集成核验。

## 验收标准

- [ ] 两个入口重新检查时按文件身份保留原选择；首次清单以外不默认全选，新增及无法还原成员不自动选中。
- [ ] 查看未选文件仍核验当前内容；该文件变化时旧差异不能再作为当前正文显示，但不能因此扩大或执行选择，未选变化也不阻止选中集合处理。
- [ ] 选中文件变化、清单替换、取消、执行、清理或会话释放后，关闭或失效正文并提示重新检查；不静默改用新清单执行。
- [ ] 部分失败后，A 已还原、B 已选未完成、C 未选的状态经过重新检查、刷新、重启和另一窗口读取仍准确；A 不重复写入、B 保持选中、C 保持未选。
- [ ] 已执行选择与实际进度依据保存结果恢复；结果不确定成员不能再次选择，也不被显示为成功或未处理。
- [ ] 读取或清单响应逆序、关闭后迟到、切换会话后迟到、组件释放后迟到均不能覆盖新状态或重新创建弹窗。
- [ ] 部分失败后的保留继续、正常保留继续、取消及历史零选关闭保持各自完成语义；错误恢复不能把关闭转换为完成。
- [ ] 助手忙碌、会话变化、清理及其他窗口使操作失效时，停止不再安全的操作，保留真实结果，并提供可用的重新检查、保留或取消路径。
- [ ] 两层弹窗叠加、清单更新移除原文件行、结果状态变化时，Escape、Tab 和焦点返回仍正确，不跳到已失效控件。
- [ ] 用真实文件、独立窗口状态及重启读取验证上述组合；旧完成及旧中断记录回归通过，保存失败和文件成功后的发送失败不导致重复处理。

## 范围边界

不引入时间自动过期、自动扩选或分批补还原；不新增预览能力或绕过前置任务的安全边界。
