## 验收标准

- [ ] 对照宿主原生弹窗和既有回滚面板检查背景、字体、圆角、阴影、遮罩、按钮、复选框和图标；不另建品牌视觉，不破坏原中文或宿主字号偏好。
- [ ] 列表信息层级、复选框、目录、状态和查看按钮稳定对齐；还原是主要动作、保留是次要动作，用户保留不显示为错误，禁用及焦点状态可辨。
- [ ] 正文大弹窗具有充足阅读空间，标题和关闭入口始终可用；长路径、同名文件、长错误、加载、降级和错误状态不造成重叠、裁切、过大空白或明显跳动。
- [ ] 差异删除／恢复有图例和符号，普通可见文字以至少 4.5:1 对比度为目标；浅色、深色、字号缩放及减少动态效果下保持可读和可操作。
- [ ] 在 375、768、1024、1440 像素视口验证；页面不横向溢出，代码长行只在正文内部滚动，窄窗口不靠缩小文字或隐去必要状态维持布局。
- [ ] 使用实际宿主控件保存浅色／深色桌面和 375 像素窄窗口截图；额外核验全选、部分选中、零选、混合结果、长差异与弹窗叠加，记录证据所在位置。
- [ ] 两个入口通过真实文件与浏览器组合验收，覆盖子集、零选、删除新增文件、限制边界、计划失效、部分失败、保留继续、跨窗口和发送失败；无外部生成副作用。
- [ ] 仓库构建、严格契约与兼容检查、相关及既有回归通过，构建与源码对应；记录实际结果和未验证限制，不将现有调查检查冒充新增功能验收。
- [ ] 保持无改动直接发送、取消保留草稿、历史仅文件和旧数据兼容；交付说明指向已确认规格及验收证据，不自动替换用户安装、不发布、不推送。
