# 按钮显示设置与范围限制联动

日期：2026-10-14。

移除「消息下方的内联编辑器」，新增「显示编辑重发按钮」。关闭新选项时隐藏用户消息的编辑重发入口，开启时恢复入口；已打开的编辑草稿保留。继续使用现有临时输入框，不改变文件回滚和会话续接流程。

「显示编辑重发按钮」控制「只允许编辑重发最后一条用户消息」能否调整；「显示重新生成按钮」控制「只允许重新生成最后一条助手回复」能否调整。关闭对应显示开关时，范围限制选项禁用并弱化显示；两个对应关系互不影响。禁用不清空范围限制值，重新开启显示开关后恢复可调整。

新显示设置默认开启，范围限制默认关闭。旧 `inlineEditorBeneathMessage` 配置不沿用为隐藏按钮的决定，新配置为 `showEditResendButton`。保存、刷新、重启及跨窗口同步沿用实际宿主设置系统。

验收覆盖四种显示开关组合、已保存范围值保留、按钮隐藏与恢复、已打开草稿、旧配置兼容、持久保存与跨窗口联动，以及浅色／深色和 375／1024 像素浏览器布局。完成后提交代码并更新已安装插件。
