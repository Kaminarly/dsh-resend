Type: task
Status: resolved

## Answer

### 原因与修复

真实 API Gateway 在插件返回结果之外提供一层通信结果。操作层原先直接读取外层 `value`，把通信成功当成业务成功，因此访问不到 `shadowedSeqs`，在记录成功结果时抛错。原测试分别验证 Gateway 和操作层，界面测试的模拟返回值省略了这一层，未覆盖组合使用。

已在操作层统一处理通信结果：通信失败继续作为失败返回；通信成功时取出业务结果，再记录重写点或读取回滚字段。新增回归组合实际 Gateway 客户端、实际宿主插件与操作层，覆盖编辑、重新生成、业务拒绝、通信失败和回滚拒绝。会话与日志使用真实 Session；智能体以接受请求的测试实现替代，不调用真实模型。

重新生成原先将绝对定位的错误框放在固定高度操作行内，遇到裁切容器时不可读。新版通过 React portal 显示提示，跟随操作位置，在窄窗口中保持位于视口内，可关闭。编辑错误位于编辑框下方，失败时保留输入内容。两处错误说明均包含中文原因、处理建议和稳定错误码；不把任意异常原文展示给用户。

设置改为独立 `settings.section`，名称「消息编辑」。当前宿主设置壳未开放自定义图标选项，但实际渲染能显示 React 标签；标签提供宿主编辑图标，仅隐藏对应入口的默认齿轮。样式通过附加 `settings.action` 注册持续挂载，因此选择其他页面时图标仍正确。保留宿主设置壳及全部导航、配置、焦点管理和槽位所有权。
