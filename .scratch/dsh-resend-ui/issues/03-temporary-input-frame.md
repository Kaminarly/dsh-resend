# 临时输入框外框与按钮优化

Status: resolved

## 要求

- 在最外层增加圆角框，同时包住「临时输入框」标签和输入区。
- 将关闭按钮移至外框右上角。
- 「在正式输入框中编辑」按钮增加协调的背景色。
- 悬停提示改为「支持引用文件、调用技能」。

## 结果

采用用户截图指定的单一布局。外框使用 DSH Desktop 主题边框和圆角；编辑按钮使用随主题变化的浅色底。按钮文字保持原样，悬停和键盘聚焦显示新提示，不可用时保留原因提示。关闭、发送和转到正式输入框的行为保持可用。

原型主来源：`codex/prototype-temporary-input-frame-20261011` 分支的 `.prototype/temporary-input-frame/README.md`、`preview.mjs`、界面代码与 `output/playwright/temporary-input-frame-*.png`。

## 验证

- 构建、语法、描述文件和宿主接口检查通过。
- 全量测试 2117 项通过，8 项跳过。
- 使用真实浏览器和已安装 DSH Desktop 控件，验证浅色、深色主题下 375、768、1024、1440px 窗口宽度；外框、关闭按钮和编辑按钮位置正常，无横向溢出。
- 验证鼠标悬停和键盘聚焦显示指定提示、长文本自动增高、删减后收缩、空白消息不可发送。
- 验证右上角关闭按钮和 Escape 可关闭编辑区，转到正式输入框保留中文文本；模拟发送失败后保留内容并显示原因。
