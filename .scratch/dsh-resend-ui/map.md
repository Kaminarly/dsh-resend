# 用户消息操作位置与原生控件样式

本轮范围、用户确认和验收结果见 [01 — 用户消息编辑入口位置与 DSH Desktop 控件样式](01-native-ui-and-user-actions-placement.md)。

## Decisions so far

- 2026-10-10：用户确认按两项建议执行。编辑入口在原用户消息下的复制图标右侧；消息与编辑器操作仅显示图标，悬停或聚焦显示名称。统一插件已有控件样式，回滚范围与确认说明继续明确显示。见 [需求 01](01-native-ui-and-user-actions-placement.md)。
- 原消息接入采用保留宿主显示组件的扩展方式，已在 DSH Desktop 2.0.17 验证；不匹配时保留原消息并显示原因。两份规范的相关章节已同步修订。
- 界面与回归验证已完成，真实会话的功能测试留给用户。用户卸载旧版后，已通过应用自带的命令环境成功安装并启用，已安装代码的隔离启动验证通过。README 已记录手动安装步骤和两种命令入口的区别。
- 2026-10-10：[需求 02](02-operation-errors-and-settings-section.md) 修复操作层遗漏通信包装的错误，重新生成错误提示改为不受操作区裁切的显示方式，设置迁为带编辑图标的「消息编辑」独立页。回归与实际控件验证通过，修复包已安装。
