# dsh-resend

`dsh-resend` 是 DSH Desktop 插件。它可以修改已经发出的提问并重新发送，也可以让助手重新回答。

## 可以做什么

- **修改并重发提问**：在用户消息旁选择编辑，改好后重新发送。编辑框支持引用文件或文件夹，也支持选择技能。
- **重新生成回答**：在助手回答旁选择重新生成，让助手从原问题重新回答。
- **先检查文件改动**：如果助手在这段对话中改过文件，插件会先列出相关文件。你可以查看内容差异，再选择还原文件、保留文件或取消操作。
- **调整操作选项**：在「DSH Resend」设置中，可以分别显示或隐藏编辑、重新生成按钮，也可以限制只能操作最新一条用户消息或助手回答。

## 使用前请留意

- 编辑或重新生成较早的消息，会让它之后的对话内容从当前对话中隐藏，并不再参与后续交流。原有会话记录不会因此删除；如果从很早的位置操作，可能会隐藏大量内容。
- 文件还原只适用于插件能够确认由助手修改的文件。命令行或其他工具造成的改动可能无法识别。
- 如果文件后来被其他操作改过，插件会拒绝覆盖，避免抹掉较新的内容。
- 编辑框不会复制旧消息里的附件。你可以重新引用文件或技能，但不能在这里重新编辑原消息的上传附件。
- 文件还原记录保存在 DSH 的数据目录中。清除某个会话的回滚数据后，就无法再用插件还原该会话较早的文件版本。

## 从 GitHub 安装

DSH Desktop 的插件安装页支持 GitHub 仓库地址。仓库公开并发布版本后，可按以下步骤安装：

1. 在 DSH Desktop 侧栏打开「插件」，选择「添加插件」。
2. 输入仓库地址和版本标签，例如 `github:OWNER/REPOSITORY#TAG`。请把 `OWNER`、`REPOSITORY` 和 `TAG` 换成项目实际信息。
3. 选择「安装」，完成后启用插件。

安装时电脑需要能够访问 GitHub，并安装 Git。插件目前不会自动更新；安装新版本时，先卸载旧版，再用新版本的标签重新安装。

**当前仓库还没有配置远程仓库地址，因此上面的地址是格式示例，不是可直接安装的链接。** 仓库发布到 GitHub 并确定版本标签后，维护者应将这里替换为真实地址。

## 兼容性

目前已在 DSH Desktop 2.0.17 上验证。其他版本尚未完成同等验证；如果安装时提示版本不兼容，请不要绕过提示。

开发与验证说明见仓库中的 `GUIDE.md`。
