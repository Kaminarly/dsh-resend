# 临时输入框独立编辑，复用宿主引用语义

DSH 当前按会话持有正式 Composer 的编辑器与 Trigger controller，不支持同一 Session 同时挂载两个原生可编辑 root。直接使用共享候选控制器会改动普通草稿；复制完整 shell 又会耦合宿主私有提交和附件流程。

用户选择由插件实现独立的临时编辑器和菜单，复用目标会话的文件搜索与 skill 列表。文件标签与 skill 最终转换为宿主等价文本，交给既有 Edit-and-resend；不转交正式 Composer，不修改 DSH 本体。代价是插件负责标签编辑、候选状态、键盘、预览及兼容验证；临时框只提供 skill 调用，不沿用正式框对其他 slash 命令的裁决。

本记录确定接入路线，具体编辑器库由隔离原型验证后选择。行为规格见 [临时输入框引用规格](../../.scratch/dsh-resend-rich-input/spec.md)，当前功能尚未实现。
