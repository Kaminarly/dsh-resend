# 多选回滚成功后结束整个回滚点

文件回滚增加多选后，用户于 2026-10-13 选择继续采用一次成功确认结束整个回滚点的规则，不提供同一回滚点的分批补还原。成功结果必须分别记录实际已还原、用户选择保留和系统无法还原，不能把未选文件算成已还原；部分失败或单纯关闭预览不算成功完成。

这一决定沿用已有回滚点的完成语义，避免将多选解释为长期待处理队列。以后若改为分批还原，需要重新定义完成状态及迁移已保存的用户保留决定，而不能简单重新开放旧入口。

用户同日确认：部分失败后明确选择「保留剩余文件并继续」，也可在保存真实结果及保留决定后终结该回滚点。取消或历史面板零选关闭不终结，结果不确定的文件继续记录为不确定，不能被伪报为成功。
