# 回滚数据清理验收记录

验证日期：2026 年 10 月 11 日。

## 实现范围

「消息编辑」设置页新增「清理无用残留」和「按会话清除回滚数据」。两个入口均先预览后确认；会话支持多选，空清单显示「无文件快照」。清理结果分别展示成功、跳过和失败情况，以及实际删除文件的内容体积。

清理目标仅来自插件内部扫描，不接受用户传入的文件路径。扫描只识别插件回滚清单、完成结果、内容对象及已知格式的遗留临时文件。宿主日志仅用于识别归属，不会被清理。路径检查覆盖 DSH 数据目录及删除目标的全部上级目录，拒绝符号链接、Windows 目录联接和异常文件；普通删除目标还拒绝硬链接。

旧版清单通过完整 Session log 匹配归属；新版清单保存会话及重写点标识，同时校验标识与文件名的对应关系。会话标题从日志读取，没有标题时使用会话 ID；项目路径来自会话头。默认存储跨 Profile 共用，自定义会话库以当前查询服务覆盖范围为准。

## 数据保护

- 对象引用按所有保留清单合并计算。仍被其他会话引用的内容保持完整；无法完整读取保留清单时保留内容对象。
- 清单删除失败时，保留对应完成结果和内容；内容删除失败时，结果将相关会话标为未完成，残留内容可再次通过「清理无用残留」处理。
- 清理计划仅包含预览时的目标和指纹。执行重新扫描，排除变化或新增的数据，不扩大已确认范围。所选会话新增或修改清单时，跳过该会话并要求重新预览。
- 跨进程会话操作锁防止同一会话的插件操作交错；存储锁保护扫描、快照写入和清理。活动标记覆盖生成回复、编辑重发和文件回滚，清理跳过忙碌会话。长时间回滚不占用其他会话的清理机会。
- 清除前持久更新会话失效标记。其他 Host 下次使用旧预览或完成记录时，丢弃内存预览、完成状态和旧文件观察值。后续新操作仍能保存回滚记录。
- 持锁进程退出后，可在确认进程已结束时回收其存储锁；未确认退出或协调状态异常时，保守保留数据并显示跳过或读取失败。

本插件写入的私有 Git 内容为松散对象，本次回收这些对象。不会对用户工作区运行 Git 清理，也不会重写外部工具手工生成的私有 Git pack 文件。

## 自动验证

`test/storage-cleanup.test.mjs` 使用临时数据目录和实际文件，包括：

- 冷会话、旧清单、新清单、空清单、标题和项目路径。
- 多会话共享内容、合并空间估算、未选会话及完成结果保留。
- 无归属数据、遗留临时文件、预览后新增内容、其他插件数据保留。
- 会话清单整体读取失败、全部日志读取失败、保留清单损坏。
- 忙碌跳过、独立进程中的生成、编辑重发和回滚活动，以及长时间操作期间继续清理其他会话。
- 清单和内容的删除失败、部分成功、重新预览后继续清理。
- 私有 Git 内容回收和保留，工作区内容不变。
- Windows 目录联接、预览后的路径替换、取消和错误计划。
- 持锁进程被终止后的恢复，以及其他窗口协调信息无法读取时的保守跳过。

`test/file-rollback.test.mjs` 通过真实 Gateway 验证清理接口，包括其他 Host 的旧恢复计划失效、旧完成结果不重新写回、清理后继续创建新回滚记录、预览阶段不删除数据，以及拒绝任意路径参数。

`test/storage-cleanup-ui.test.mjs` 驱动构建后的 Client bundle，验证多选、确认前不执行、取消、空状态、读取失败、通信中断、部分失败和中英文文案。

最终检查结果：

- `npm run build`：通过，11 个构建文件已同步。
- `npm run check`：通过，包含语法、四个 Remote 接口的一致性及已安装宿主契约检查。
- `npm test`：116 个测试文件通过，2113 项通过，8 项按原有条件跳过。
- `npm run probe`：隔离 Profile 中插件注册、Host 启动、启动审计及 Client 加载均通过。

## 页面验证与边界

通过 `scripts/preview-ui.mjs` 使用已安装 DSH Desktop 的 React、设置面板、控件和主题，实际点击两个清理入口、多选、预览和确认，检查空间、删除影响和跳过原因。桌面视口及 800 × 900 视口中的确认按钮、文案和列表可正常显示。截图保存在 `output/playwright/cache-cleanup-preview.png` 和 `output/playwright/cache-cleanup-compact.png`。

390 像素宽度下，宿主设置面板的固定侧栏会挤压整个设置内容区域；此验证不作为移动端兼容承诺。页面演示只使用模拟数据；实际删除验证均使用隔离临时目录，没有清理用户真实数据，没有安装到用户 Profile 或重启用户应用。跨窗口保护适用于已升级到本版本的 Host plugin；仍运行旧版本插件的窗口需在升级后重启。
