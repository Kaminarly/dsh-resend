## 本轮交付

补齐可重复运行的 Bundle 验收：重建、语法与宿主契约检查、打包、解包逐文件比较、隔离 Profile 启动，以及直接加载解包所得 Client 的真实浏览器交互。每次运行保存独立安装包、文件摘要、检查输出和浏览器证据；`output/rich-input-release/latest.json` 只在整体验收通过后更新。

浏览器使用已安装 DSH Desktop 的 React、按钮、图标、主题和插件实际中文文案。修复真实鼠标单击文件标签不能预览的问题：编辑器在单击时自动选中标签，原判断误认为用户正在拖选；现在允许单击产生的标签选中，并继续排除实际拖选。原有中文文案、三行起始高度、内容伸缩和蓝色发送按钮保留。

## 浏览器覆盖

- 历史顺序和全文、同名不同路径、中文与空格、文件与目录、外部绝对路径、多个 skill；删除、替换和未知文本保留。
- 目录下钻与返回上级；最终目录引用不吞入正文；句中触发词和选区替换；邮箱、路径和分数不误触发。
- Enter/Tab 选择、方向键循环和当前选项可见、分层 Escape、Shift+Enter 换行、空白禁发；输入法确认事件与 `229` 键码不触发发送。
- 浏览器权限内的真实剪贴板，键盘复制、剪切、粘贴、撤销和重做；引用按完整路径保留。
- 真实鼠标单击文件、目录与外部路径，双击选择和拖选不改写正文、不发送；skill 按当前可用目录精确预览；能力缺失和打开失败提示准确。
- 同一目标的两个独立浏览器页面、Session 与消息目标切换；普通正文、附件、选区和撤销保留。
- 延迟及逆序候选、关闭与重开、连接重置、预设变化、目标失效；旧响应和旧按钮不插入新草稿。
- 文件与 skill 查询失败或接口缺失、失效和仅模型可调用 skill；准确提示后仍可按原文重发。
- 预检冻结、取消恢复、发送前拒绝和异常保留；失败补发使用首次完整文本，不按后续编辑重新生成。
- 真实宿主 skill 加载钩子接收用户来源文本，加载代表性可调用技能并去重；同名命令仅按 skill 处理。

## 实际验证边界

真实执行：Edge 页面、编辑器、键盘与剪贴板交互、宿主控件及主题、已安装宿主的 skill 加载钩子、隔离 Profile 的 Bundle 加载。候选 RPC、skill 注册目录、资源打开回调和消息接收方使用隔离替身；不将这些结果描述为真实模型回复或真实资源窗口展示。

未验证：宿主 Electron 窗口中的最终资源展示、真实 Session 的文件候选 RPC、实际系统中文输入法窗口、模型读取工作文件或生成回复，以及刷新后临时草稿恢复。输入法检查是在真实浏览器中派发确认事件；双击中的第一次单击可能调用预览，随后仍能选择和编辑文字。

文件还原与保留后读取内容、额外引用不扩大回滚清单、补发不重复还原和 Rewind point 由现有集成回归检查支持；浏览器验证固定发送文本和操作阶段，隔离接收方不模拟真实模型读文件。验收没有安装到真实 Profile、修改真实用户会话或发起模型请求。

## 复现

```powershell
npm run build
npm run check
npm test
npm run acceptance:bundle
```

`npm run acceptance:bundle` 需要 npm 环境、已安装且可读取的 DSH Desktop、Edge 和可执行的 `tar`。能力缺失会明确失败，不能把跳过的宿主验证算作交付成功。可通过 `EDITOR_BROWSER_CHANNEL` 指定已有的浏览器通道；默认 `msedge`。单独运行浏览器脚本可通过 `EDITOR_BUNDLE_PATH` 指向待验收的 Client 文件。
