# 文件回滚内容预览与多选还原：整体交付验收

日期：2026-10-14。范围依据[已确认规格](../.scratch/dsh-resend-rollback-content-preview/spec.md)第 1–13 节及[任务 05](../.scratch/dsh-resend-rollback-content-preview/issues/05-native-visual-and-delivery.md)。任务 01–04 已完成，本次完成整体视觉修整和交付组合验收。

## 本次修整

文件列表使用稳定的列位置，窄面板将状态和查看入口放到下一行，保留文件图标、完整目录和必要状态。还原按钮恢复宿主主要样式，保留使用次要样式。用户选择保留使用中性文字，无法还原同时提供警告图标与原因。文字使用宿主语义变量；没有引入新字体、品牌色或图标体系。原有中文保留。

逐行复选框复用宿主 `Checkbox`。宿主复选框只接受布尔选中状态，没有提供部分选中的设置入口；批量选择因此保留原生三态复选框，并采用宿主颜色和焦点变量。选择区与查看按钮分开，触屏选择区至少为 44 × 44 像素。

正文继续复用宿主 `Modal`、按钮和代码字体。正文宽度以 960 像素为基准，窄窗口利用可用宽度；路径、版本信息及正文各自在内部滚动，并可通过键盘聚焦。加载、降级及读取失败保留同一正文区域，读取完成不推移正文位置。标题和关闭按钮保持可见。叠加弹窗沿用现有前景键盘隔离，避免重复模糊或加深遮罩。减少动态效果时取消自动平滑滚动及本功能控件的动画与过渡。

## 真实文件与浏览器组合验收

通过浏览器点击两个公开入口，HTTP 仅转发到本仓库构建出的严格 Gateway；文件快照、回滚选择、执行和进度保存均由交付 Host plugin 处理。每个场景使用独立临时目录及实际 `Session`。提示词接收由接受／拒绝服务替身控制，不接入外部模型。

通过 18 个场景：

- 两个入口分别验证子集还原、查看未选文件、删除新增文件、删除新增空文件、零选关闭、选中文件变化拒绝执行。
- 两个入口分别验证部分失败、另一浏览器页面及独立 Host plugin 读取同一进度、重新创建 Host plugin 后的选择恢复。A 已还原不重复处理，B 保持选中，原未选的新增文件保持未选。
- 两个入口分别验证 3 MiB、10,000 行、20,000 个 Unicode 码点恰好相等及超过边界的正文。降级不取消原选择，查看不写文件或会话日志。
- 重发前验证零选保留全部文件并继续、无文件变化直接发送、部分失败后保留剩余文件并继续。
- 模拟完成结果保存失败：停止发送；恢复保存后继续，已还原文件不重复处理。模拟发送未被接收：补发只续接发送，已还原文件之后的用户修改没有被覆盖。

完整请求、真实响应及每场景的会话写入和提示词接收计数见 `output/playwright/rollback-browser-result.json`。部分失败和保存失败在文件系统边界注入，其他文件读写使用真实临时文件；执行后读取实际字节核对中文、BOM 和 CRLF 恢复结果。

## 构建、回归与交付包

`npm run build` 和 `npm run check` 通过。检查包含源文件与构建语法、Host／Client 严格契约一致性、当前安装宿主的契约及兼容检查。全量回归为 129 个测试文件通过、1 个按原有条件跳过；2,340 项通过、10 项按原有条件跳过，覆盖既有旧完成及旧中断记录、无改动发送、草稿保留、历史仅文件、保存失败与发送失败。正文键盘检查在先观察失败后修复，并重新通过相关回归。

运行 `npm run acceptance:rollback:bundle` 在 `output/rollback-release/<运行时间>/` 生成交付包。该命令再次构建、检查并逐字节比对独立重建结果；解包后核对每个交付文件，再使用解包出的 Client bundle 运行视觉及真实文件浏览器组合验收。Host plugin 使用工作区构建，已确认与解包 Host 文件逐字节一致。

每次交付目录包含：

- `dsh-resend-0.1.0.tgz`：本地交付包。
- `acceptance.json`：包及文件 SHA-256、构建起点、工作区是否有未提交改动、检查结果及验证边界。
- `build.log`、`check.log`、`visual.log`、`browser.log`：实际运行输出。
- `evidence/`：本次截图、视觉测量及真实接口记录，避免依赖会被下一次运行覆盖的公共输出目录。

这些本地输出不纳入版本控制。代码尚未提交时，`sourceHead` 是构建基准，`worktreeDirty` 为 true；交付字节以逐文件哈希和解包比对为准，不将基准提交冒充包含本次改动的提交。

## 验证边界

本项没有替换用户已安装的 Bundle，没有发布或推送。浏览器使用实际宿主控件和主题，但页面本身是隔离验收页面；未在用户现有桌面会话中执行文件还原。独立窗口与重启恢复分别使用独立浏览器页面／Host plugin 和重新创建的 Host plugin 验证，不声称完成操作系统重启验收。发送失败验证提示词接收与补发规则，不验证外部模型实际输出。

原有存储调查和兼容性探测仅作为背景；上述布局、正文限制、浏览器真实文件执行及交付包核对是本次新增验收。最终两路代码审查结论在确认后按 implement 流程写入任务 05；本说明不提前将任务标为已解决。
